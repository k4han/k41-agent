Ask on GitHub
What exactly is K41 Agent?+

K41 Agent is an open-source AI workspace assistant that runs on your machine. Its web dashboard brings together chat, workspace files, background tasks, model settings, and optional integrations.

Is it free to use?+

K41 Agent is free, MIT-licensed software. You bring your own model provider and credentials. Any model usage or optional external service costs are billed by those providers.

Does everything stay on my machine?+

The agent runtime, configuration, and runtime data are local. When you use a model provider or an external integration, the content needed for those requests is sent to that service. Local runtime does not mean every model runs offline.

Which operating systems are supported?+

The one-command installers support Windows, macOS, and Linux. The installer prepares the Python environment with uv and downloads the release package. Browser automation additionally requires a local Chrome or Chromium installation.

How do I update K41 Agent?+

Run k41 update in your terminal. The updater checks the latest GitHub release, backs up the installed source, and restarts the server if it was running. Your configuration and runtime data are kept.
